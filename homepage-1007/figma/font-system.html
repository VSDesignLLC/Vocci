品牌字体方案 · 六选一

六组候选全部为 SIL Open Font License 1.1 开源字体：可免费用于网页、印刷、App、视频、广告等商业用途，可嵌入软件与文件，唯一限制是不能单独售卖字体文件本身。

每个方案下方是它在当前官网中的具体用法（桌面 1440 的真实字号），可直接作为字体规范的起点。

贯穿所有物料

选定后，网页、印刷、App、视频统一使用同一套字体与层级。

品牌字体 ≤ 2–3 种

主字体覆盖绝大多数文字；Mono 只做系统信息；衬线（方案 04 / 06）只用于大标题。

特殊字体小范围使用

Mono 用于标签、编号、参数、模型 / 系统类物料，不用于正文与长段落。

方案 01

Inter + JetBrains Mono

中性 · 通用 · 理性2 种字体全部 SIL OFL 1.1 · 可商用

Inter 是为屏幕界面设计的无衬线体，几乎在任何尺寸和介质下都稳定清晰；JetBrains Mono 是为代码阅读设计的等宽字体，字形开阔，做标签和系统信息很利落。整体最"安全"，个性最弱。

适合：适合想要稳定、不出错、跨平台一致性最高的方向。

注意：辨识度偏低，与大量科技产品雷同。

方案 02

Geist + Geist Mono

几何 · 现代 · AI 科技感1 个家族全部 SIL OFL 1.1 · 可商用

Geist 由 Vercel 发布，Sans 与 Mono 同一家族、同一套骨架，等宽版本只是把字宽统一，因此全套视觉最统一。几何感明显，偏 AI / 开发者产品。

适合：最符合"品牌字体越少越好"，一个家族覆盖网页、App、视频和系统物料。

注意：较新，部分印刷场景需自行安装字体文件；气质偏冷。

方案 03

Manrope + IBM Plex Mono

圆润 · 温和 · 亲和2 种字体全部 SIL OFL 1.1 · 可商用

Manrope 字形更圆、更开放，弱化工程感，贴近"戴在手上的饰品"的亲和与日常；标签沿用现在的 IBM Plex Mono，和现有设计衔接最顺。

适合：想在科技感之外增加温度、面向更广泛的日常用户。

注意：小字号正文略宽，长段落需注意行长。

方案 04

DM Sans + Newsreader + DM Mono

编辑感 · 精品 · 叙事3 种字体（衬线仅大标题）全部 SIL OFL 1.1 · 可商用

正文和标签用同一家族的 DM Sans / DM Mono；大标题用 Newsreader，一款为屏幕阅读设计、带光学尺寸的衬线体，对比适中，有杂志式的叙事感。

适合：品牌想强调"真实生活、人与对话"，印刷物料和视频片头表现力最强。

注意：三种字体，规则必须严格：衬线只用于 H1/H2。

方案 05

Hanken Grotesk + Fragment Mono

克制 · 精致 · 瑞士风2 种字体全部 SIL OFL 1.1 · 可商用

Hanken Grotesk 是偏国际主义风格的 Grotesk，比例紧凑、细节克制，接近高端硬件品牌的气质；Fragment Mono 线条细，适合做系统 / 模型类信息的点缀。

适合：希望品牌更像高端硬件，而非 App 或互联网产品。

注意：Fragment Mono 只有常规字重，标签层级靠字号和颜色区分。

方案 06

DM Sans + Source Serif 4 + DM Mono

素净 · 理性 · 可信3 种字体（衬线仅大标题）全部 SIL OFL 1.1 · 可商用

与方案 04 同结构，大标题换成 Adobe 出品的 Source Serif 4：更素净、结构更理性，书卷气更少，和科技产品更搭，同时保留衬线带来的可信与质感。

适合：想要衬线的质感，但不想太文艺。

注意：同方案 04，需严格限制衬线的使用范围。
