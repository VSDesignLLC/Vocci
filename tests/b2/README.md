## 素材与实现

- [素材目录](../../assets/b2-tests/)；[出图提示词与来源](../../assets/b2-tests/prompts.md)。
- 四张截图保存在 `assets/b2-tests/source/`，用户明确授权本地抠图。
- 最终 `ring-silver.png`、`ring-black.png`、`ring-gold.png`、`ring-gray.png` 是原截图像素经轮廓蒙版提取的 RGBA PNG，内孔和外部均透明。保留各自原始角度，没有用生成图替代原产品。
- `source/cutout-paths.json` 保存四组可编辑轮廓，`source/export-cutouts.py` 可复现导出。源截图分辨率有限，本轮用于小卡片测试。
- 开场是现有产品 PNG + SVG 光点与蒙版的运动样机，不是真实 3D 自转。戒指轻转、光点环绕；系统开启减少动态效果时直接展示 Hero。
- Highlight 仅生成一张。原图已有局部虚化与细线；网页以同一图片的两层对齐实现固定 4px 焦点区，保持场景连续。文案放在独立 HTML 层。

## Annotation 第二轮

四个方向在同一测试页切换，URL hash 可直达：

- `#original`：恢复 B1.5 第一张 highlight 的完整 annotation、底部短句与状态标签，作为对照。
- `#cards`：明亮饱和的紫色录音玻璃卡 + 橙色下一步玻璃卡；透视、扭转和光泽表达从戒指到软件的转换。紫色、橙色用于软件交互的局部表达，整体页面仍继承黑白视觉系统。文字与时间为说明性示例。
- `#software`：直接使用现有 `assets/ui/image 6349276.png` 转录页截图，浮动容器呈现软件信息；裁切只在 CSS 容器中实现，原素材未编辑。
- `#type`：文字沿手臂和握手区的路径展开，以对话片段表现录音，保留记录状态小卡。文字与时间为说明性示例。

所有方向保留相同标题与清晰窗口，连接线的起点根据照片坐标重新计算，随桌面 viewport 对齐戒指。测试页保留独立状态，不合并 B1.5。

第二轮验证：首屏 Silver 在约 2 秒内完整切到 Black；手动选择暂停轮换。四种标注切换、URL hash、键盘切换、隐藏文案、4px blur、1280 / 1440 / 1920 宽度检查通过，无缺失图片或脚本错误。

## Annotation 第三轮 · 保留多种叙事语言

彩色透视卡片已从低饱和土黄／灰紫改为明亮的紫色／橙色，保留半透明背景、背景模糊、亮边与透视。

| 视觉类型 | 叙事用途 | 后续章节应用建议 |
| --- | --- | --- |
| 原版标注 | 解释动作、功能与产品细节 | 物理按钮、双击操作、日常佩戴 |
| 彩色透视 | 表达戒指与软件的交互及结果 | 录音生成摘要、行动项、发送到 AI |
| 软件 UI | 展示可具体理解的产品界面 | 转录、检索、回看、管理内容 |
| 文字轨迹 | 让对话与录音变得可见 | 商务交流、灵感捕捉、强调在场感 |

每屏选择一种主要表达方式，保持统一的细线连接和焦点窗口，避免四种样式在同一画面争抢注意力。当前仍在独立测试页中预览。

正式 B2 按叙事分配上述视觉类型；每张 highlight 最多一张彩色透视卡。此处彩色透视测试仍保留紫橙双卡，供历史对照。
