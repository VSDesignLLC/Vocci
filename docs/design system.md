## B1.5 采用规则

1. 页面按 1440px 设计，本轮不制作响应式分支。外侧留 8px，内容框宽 1424px；导航顶距 8px，高 64px。
2. 所有布局框、按钮、图片窗统一 4px radius；导航为 `4px 4px 0 0`，便于与章节连接。圆形产品本体、手机形状与圆点保留其自然形态。
3. 网格主要表现为 section 外框、左右连续竖线和少量分栏线。移除装饰十字。Hero 原图文、内部网格与相对构图保留。
4. Geist 用于新增章节，400 正文、500 标题；Hero 保留 B1 原字体与字号。注释用 Geist 14–16px；少量时间和状态用等宽字。
5. 强调色用于购物车、步骤当前状态、FAQ 分类与 footer。大面积保持白和浅灰；照片维持原自然肤色。
6. 通用间距采用 8 / 16 / 24 / 32 / 48 / 64 / 96px。每个满屏章节的可视高度为 `100vh − 80px`。

## 本轮边界与素材依据

- 本轮为新的 `vocci-optionb1.5.html`；B1 和原四方案继续保留。
- 四步沿用用户指定的 Double-tap / Transcribed / Long-press / Agent-ready 顺序。长按与集成细节依产品 Brief 边界表述，演示消息属于示例，不代表实际发送。
- 戒指特写暂用现有 PNG，通过容器裁切表现镜头变化。透明内部属于未来有准确结构模型后的镜头选项。
- Breather 使用原透明双手图的两份 CSS 裁切与独立位移，保持原产品和手部细节，当前无动画。
- 图片复用 B1 概念摄影、项目产品图、现有 App 截图和制造图库。Logo 与 testimonial 没有已核实素材时使用明确标注的版式占位。
- 字体使用 Google Fonts 官方仓库的 Geist 开源文件，随文件保留 OFL 许可证；不复制 Mira 的品牌 Logo、用户评价或产品事实。

## 设计复核

本稿严格按用户拼版组织观看节奏：全屏影像建立用途，留白 breather 暂停，白底步骤解释操作，放大镜头解释硬件，制造画面和信任区收束。Hero 不再承担整站改版；本轮的变化集中在章节关系和镜头尺度。
