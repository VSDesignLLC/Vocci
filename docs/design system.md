## B1.5 采用规则

1. 以 1440px 为设计基准，支持 1280px 及以上桌面宽度。普通内容跟随 `viewport − 16px`，两侧各一条贯穿页面的 1px rail。取消各章节独立外框。Highlights 突破 rail，宽高均铺满视口。
2. 普通控件与影像标注沿用 4px radius。导航改成左右两个独立玻璃区域：左侧 Vocci Logo，右侧所有链接与购物车图标；两者顶距 16px，高 64px，侧距 24px。中间透明留空。Highlights 内向下滚动时导航向上移出（320ms ease-out），向上滚动时向下移入（320ms ease-in）；离开该章节后保持显示。
3. 线条采用 Hero 网格的浅色 `#E5E5E0`，1px。Hero 原图文与内部网格保留。产品设计与制造共用连续的 80px 背景网格；Logo、testimonial、FAQ 共用无章节边框的白底。
4. Geist 用于新增章节，400 正文、500 标题；Hero 保留 B1 原字体与字号。注释用 Geist 14–16px；少量时间和状态用等宽字。
5. 主色为黑色 `#000000`，用于购物车、当前步骤与主要按钮。土黄色 `#BDA367` 仅用于少量状态点和连接线。界面以黑白与浅灰为主，照片保留自然颜色。Footer 按最新参考恢复为原 B1 浅底四栏和细分隔线；Mira 橙色仅保留在来源记录中。
6. 通用间距采用 8 / 16 / 24 / 32 / 48 / 64 / 96px。普通固定步骤舞台高度为 `max(690px, 100vh − 80px)`；highlights 则为完整 `100vh`，固定顶线为 0。
7. 导航、影像 annotation / label 与产品细节选项共用玻璃样式：42% 白色底、22px 背景模糊、135% 饱和度、细微反光与浅色边线。产品选项用深一档的网格线保留边界。导航 z-index 1000，内容可从下方经过。
8. 四步仅使用一个 sticky 舞台。左侧只显示当前步骤标题和说明，与中间图片一起进行 400ms 淡入淡出；右侧保留全部 1–4 进度，已到达步骤变黑并聚在上方，未到达步骤灰色留在下方。自然向下滚动、反向滚动和点击步骤均可切换。
9. 产品细节选项收起 80px、展开 160px，起点与边界落在 80px 网格上，保留加减号。右侧图片容器不再裁切图片，仅在整个产品章节的外缘裁切；大图镜头向右调整，避免在文字列旁出现截断的直线。制造章节标题上方留白增至 144px。
10. 每张 highlight 完整出现后保持额外 `45vh` 的滚动距离，再用 `100vh` 滚动距离覆盖下一张；第五张同样停留，再整体上移露出已在后方的 breather。使用滚动距离，不设置计时锁或拦截滚轮。

## 本轮边界与素材依据

- 本轮为新的 `2026-09-07-option-b1.5.html`；B1 和原四方案继续保留。
- 四步沿用用户指定的 Double-tap / Transcribed / Long-press / Agent-ready 顺序。长按与集成细节依产品 Brief 边界表述，演示消息属于示例，不代表实际发送。
- 戒指特写暂用现有 PNG，通过容器裁切表现镜头变化。透明内部属于未来有准确结构模型后的镜头选项。
- Breather 使用原透明双手图的两份 CSS 裁切与独立位移，保持原产品和手部细节，当前无动画。
- 图片复用 B1 概念摄影、项目产品图、现有 App 截图和制造图库。Logo 与 testimonial 没有已核实素材时使用明确标注的版式占位。
- 字体使用 Google Fonts 官方仓库的 Geist 开源文件，随文件保留 OFL 许可证；不复制 Mira 的品牌 Logo、用户评价或产品事实。

## 设计复核

本稿严格按用户拼版组织观看节奏：全屏影像建立用途，留白 breather 暂停，白底步骤解释操作，放大镜头解释硬件，制造画面和信任区收束。Hero 不再承担整站改版；本轮的变化集中在章节关系和镜头尺度。

## B2 narrative imagery · 2026-09-08

在 [B2](../2026-09-08-option-b2.html) 中，保留黑白主视觉与两侧 rail。场景采用冷中性色、局部清晰窗口和 4px 外围虚化；不同叙事分别使用文字轨迹、彩色透视卡、真实 App UI、中性功能标注。紫色与橙色是软件交互的局部强调色，每张 highlight 最多一张彩色透视卡，不扩展到导航、CTA 或通用按钮。Hero 四色每 1.4 秒轮换，开场采用已确认的戒指与光点蒙版动效。详见 [B2 交付记录](0908-b2-delivery.md)。
