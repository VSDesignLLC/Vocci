# B1 本轮设计与文案定稿依据

日期：2026-09-07。用户授权：按推荐定稿本轮 message，融合 Option 1 手部图片与 Option 2 网格视觉，补充商务交流、按键、工作、拿手机场景。

## 设计决定

- 保留 Option 2 的外框、交叉线、五张叠卡、四步流程与细节轮播。新稿单独保存为 `vocci-option2-b1.html`，入口加入 B1，原方案可对照。
- 色彩沿用纸白 `#f7f7f5`、浅灰 `#efefec`、墨色 `#141412`、边线 `#dcdcd6`，增加来自衬衫与照片的蓝灰 `#557184`；肤色来自摄影。原金色不再作为标注主色。
- Helvetica Neue 用于标题与正文，系统等宽体仅用于简短的操作、图注与流程标签。大标题与产品含义承担识别；不引入无关装饰字体。
- 首屏：居中文字，下方双手横跨原网格；保留一个小型戒指细节窗。图像标注对准戒指或动作，文字放在安静区域。
- 五张叠卡：左图右文；手机上图下文、顺序阅读。短标签解释用户动作与价值；每图最多两组标注，必要时一条次级网格线。
- 新场景为 AI 生成概念摄影；沿用真实项目产品参考。生成细节与正式 ID 尚须核对，不作为制造精度或真实用户证据。
- SVG 路径和 HTML 图注独立于照片。借鉴参考 1 的节点引线、参考 2 的人与文字关系、参考 3 的框线裁切；避免大量曲线文字影响阅读。

## 对 brief 的复核

这轮的变化集中在图文和局部视觉层级。原先重复 Context/Presence 的五张卡被改为连续的使用价值；网格和细线仍是 Option 2 的识别依据。暖色只来自真实肌肤和日光，保留白与灰的工程底色。软件通过可读示例显现，避免每张照片都叠加复杂界面。
