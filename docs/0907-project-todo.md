## 5. P1：戒指 3D 与素材

### 5.1 先收集，后决定制作方式

- [ ] **3D-01 / 设计师协调、Vocci ID/硬件提供：**确认是否已有戒指与充电盒 CAD 或渲染源文件；常见可用来源包括 STEP、原生建模文件、OBJ/FBX/GLB。没有源模型时，提供多视角尺寸图与实物照片，另评估重建工作量。
- [ ] **3D-02 / Vocci ID：**确认最终销售版本的外形、内外圈、按键、开孔、Logo、接缝、颜色、材质及准确尺寸。完成标准：指定一份作为视觉基准的产品 ID。
- [ ] **3D-03 / 助手 + 设计师：**列出最少模型与镜头集合。第一轮优先一枚最终外形的戒指、一套主材质、6 个关键状态；充电盒按叙事需要加入。
- [ ] **3D-04 / 设计师 + 3D 制作方：**确定工作室白光、佩戴环境光与微距高光的共同材质标准，核对金属、肤色、尺度与按钮朝向。
- [ ] **3D-05 / 助手：**用低成本静帧分镜验证相机、构图、文案空间与转场；再确定网页采用实时模型、预渲染序列、视频或组合。视觉参考不等于已经确认对方的技术实现。
- [ ] **3D-06 / 制作方 + 助手：**按选定方式输出可编辑源资产、网页资产和静态后备图，并测试加载、清晰度、滚动与移动端表现。

如使用内部结构或爆炸图，必须有可公开且准确的结构资料；未获得资料时，使用外观、手势与界面表达，不虚构内部零件。
